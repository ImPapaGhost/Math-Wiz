# Changelog

## 2.0

- Expression keypad with arithmetic, trig, logarithms, powers, and square roots.
- DEG/RAD modes, x values, and recent results.
- Graphs with pan, zoom, and trace.
- Examples and help screens.
- Parser and button tests, updated FAP, and firmware build workflow.
- Symbolic derivatives and integrals from version 1 are no longer included.

## 1.1.0

- Added user-defined x values for polynomial evaluation.
- Improved navigation flow.

## 1.0.0

- Polynomial evaluation up to sixth degree.
- Polynomial derivative and integral operations.
- Horizontal scrolling and button-driven coefficient entry.
